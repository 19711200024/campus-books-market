## 张明（35%）— 后端负责人

### 负责模块

后端整体架构设计与实现，包括数据库设计、API 开发、认证体系、部署方案。

### 具体工作清单

**架构与设计**
- 设计系统整体前后端分离架构，制定 RESTful API 规范
- 编写 [API_SPEC.md](./API_SPEC.md)，作为前后端开发契约
- 设计数据库表结构（users / books / orders / messages / favorites），编写 `schema.sql`
- 设计订单状态流转状态机，明确各状态变更的权限与联动逻辑

**后端开发**
- 搭建 Express 项目骨架：`server.js` 入口、中间件注册、路由挂载
- 实现 JWT 认证中间件 `middleware/auth.js`：Token 签发与验证、`req.user` 挂载
- 实现用户认证模块：注册（bcrypt 密码哈希）、登录、获取/更新个人信息
- 实现书籍管理 API：列表分页查询、关键词模糊搜索、分类/成色筛选、多维度排序
- 实现书籍 CRUD：发布、编辑、删除、状态变更（在售/已预订/已售出）
- 实现订单 API：创建订单、订单状态流转、买卖方订单列表
- 实现收藏 API：添加收藏、取消收藏、收藏列表
- 实现站内留言 API：发送留言、留言列表、标记已读
- 实现首页统计 API：书籍总数、用户总数、最近发布书籍
- 配置 Multer 文件上传中间件，支持多图片上传与大小限制

**数据库**
- 使用 better-sqlite3 连接 SQLite 数据库
- 开启外键约束 `PRAGMA foreign_keys = ON`
- 为高频查询字段创建索引（seller_id、status、buyer_id、seller_id 等）
- 编写种子数据脚本 `seed.js`

**部署运维**
- 编写后端 Dockerfile
- 编写 docker-compose.yml，编排前后端服务
- 配置环境变量（JWT_SECRET、PORT 等）
- 部署到免费云平台（Render / Railway）并调试

## 李华（30%）— 前端负责人

### 负责模块

前端整体架构设计、核心页面开发、公共组件封装、状态管理与路由。

### 具体工作清单

**前端架构**
- 搭建 Vue 3 + Vite 项目骨架
- 配置 Vue Router，设计路由表，实现全局前置守卫（登录拦截）
- 集成 Pinia，设计用户状态 store（登录态管理、token 持久化）
- 封装 Axios 实例：请求拦截器自动携带 Token、响应拦截器统一处理错误码与 401 跳转

**核心页面开发**
- 首页：轮播/统计展示、最新书籍、推荐书籍区域
- 书籍列表页：搜索栏、筛选器（分类/成色/排序）、分页、书籍卡片网格布局
- 书籍详情页：图片轮播、书籍信息展示、卖家信息、收藏按钮、"想要"按钮
- 用户认证页：登录页、注册页表单设计与校验
- 个人中心：个人资料编辑、我的发布管理

**公共组件封装**
- 封装 `BookCard.vue` 书籍卡片组件（列表页、首页推荐、收藏页复用）
- 封装 `ImageUpload.vue` 图片上传组件（基于 el-upload，支持多图预览删除）
- 封装 `ConditionTag.vue` 成色标签组件（不同成色显示不同颜色）
- 封装 `AppPagination.vue` 分页组件

**前端工程**
- 配置 Vite 开发代理（`/api`、`/uploads` 转发到后端）
- 统一页面布局：顶部导航栏 + 侧边栏 + 主内容区
- 处理响应式布局适配

## 王芳（20%）— 前端业务模块开发

### 负责模块

书籍发布与编辑、交易订单流程前端、站内消息模块、UI 细节优化。

### 具体工作清单

**书籍发布与编辑**
- 书籍发布表单页：书名、作者、ISBN、价格、原价、成色选择、分类选择、关联课程、描述、图片上传
- ISBN 识别填单交互（输入 ISBN 后自动填充信息）
- 书籍编辑页：预填已有数据，支持部分更新
- 我的发布列表：按状态筛选（在售/已预订/已售出），支持上下架操作

**交易订单模块**
- 下单弹窗：确认书籍信息、填写自提点、提交订单
- 买家订单页：我买到的订单列表、订单详情、确认收货操作
- 卖家订单页：我卖出的订单列表、确认订单、标记完成操作
- 订单状态时间线展示

**站内消息模块**
- 消息列表页：按书籍分组的会话列表、未读红点提示
- 消息对话视图：展示与某本书相关的留言记录、发送新留言
- 未读消息数角标（导航栏消息图标上）

**UI/UX 优化**
- Element Plus 主题色定制（校园蓝主色调）
- 空状态设计：暂无书籍、暂无订单、暂无消息
- 加载状态：骨架屏、Loading 指令
- 交互反馈：ElMessage 消息提示、ElMessageBox 确认对话框
- 收藏页：收藏书籍列表、取消收藏

## 协作方式

- **每周例会**：每周固定时间同步进度、讨论问题、分配下周任务
- **代码托管**：使用 Git 进行版本控制，分支管理（main / dev / feature 分支）
- **任务看板**：使用 Trello/飞书看板跟踪任务状态（待办/进行中/已完成）
- **前后端并行**：通过 API 文档约定接口，前端使用 Mock 数据先行开发，后端接口完成后联调
- **联调测试**：后端接口开发完成后，前后端一起进行联调，确保接口与前端调用一致
